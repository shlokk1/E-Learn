============================================================

Use a SIMPLE, INDUSTRY-STANDARD interface.

Avoid excessive:

- Gradients
- Neon colors
- Glassmorphism
- Huge shadows
- Decorative animations
- Excessive rounded cards
- Floating elements everywhere
- Complex visual effects
- Overly colorful backgrounds

look "modern."

- Solid colors
- White/light surfaces
- Neutral gray backgrounds
- One primary brand color
- Semantic colors for statuses
- Simple borders
- Subtle shadows
- Moderate border radius
- Consistent spacing
- Clear typography
- Strong visual hierarchy

============================================================
6. LIGHT MODE + DARK MODE
============================================================

The application MUST support:

LIGHT MODE
DARK MODE

This should be designed into the application from the
beginning.

Do NOT implement dark mode as an afterthought.

Use CSS variables/design tokens so the theme can switch
cleanly.

For example conceptually:

Light:

--primary
--background
--surface
--text
--muted-text
--border
--success
--warning
--danger

Dark:

The same variables should receive dark-compatible values.

The theme toggle should be available in an appropriate
location, preferably the global header or settings.

Use JavaScript localStorage so the user's selected theme
can persist after page refresh.

Respect the user's system theme if appropriate on first visit.

The dark theme must remain accessible and readable.

Do not simply invert colors.

============================================================
9. PROJECT PURPOSE
============================================================

The main purpose of this portal is:

1. Help students access official educational materials.
2. Allow students to raise academic doubts.
3. Ensure doubts are reviewed before mentors answer them.
4. Allow teachers/mentors to approve or reject doubts.
5. Allow mentors to answer approved doubts.
6. Allow students to continue the discussion.
7. Provide a digital library containing textbooks and guide books.
8. Provide a student community for peer-to-peer learning.
9. Monitor community conversations for inappropriate language.
10. Allow teachers to take action when necessary.
11. Provide announcements and notifications.
12. Help students stay connected with educational content.

     ↓
