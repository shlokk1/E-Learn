============================================================
2. ROLE OF THE ADMIN
============================================================

The Admin is responsible for managing the overall platform.

The Admin is NOT primarily responsible for:

- Teaching students
- Answering every doubt
- Participating in every discussion
- Creating normal student-level academic conversations

Those are primarily Teacher/Mentor responsibilities.

The Admin's purpose is:

PLATFORM MANAGEMENT
+
USER MANAGEMENT
+
ACADEMIC STRUCTURE MANAGEMENT
+
CONTENT MANAGEMENT
+
ANNOUNCEMENT MANAGEMENT
+
MODERATION OVERSIGHT
+
PLATFORM MONITORING

============================================================
65. IMPORTANT UI RULE
============================================================

Do not put every feature into a giant dashboard.

The dashboard is an OVERVIEW.

Detailed management happens on separate pages.

For example:

Dashboard
   ↓
Students
   ↓
Student Details


Dashboard
   ↓
Library
   ↓
Resource Details


Dashboard
   ↓
Community Moderation
   ↓
Flag Details


This keeps the interface manageable.


============================================================
66. PERFORMANCE
============================================================

The application should remain lightweight.

Avoid:

- Huge image files
- Background videos
- Unnecessary animation
- Large libraries
- Excessive JavaScript


The platform should be usable on slower devices and
connections.


============================================================
67. CODE QUALITY
============================================================

Code must be:

Readable

Simple

Maintainable

Modular

Well-commented where useful

Easy for students to understand


Do not over-engineer.

Do not introduce design patterns unless they solve an
actual problem.


============================================================
68. ACCESSIBILITY
============================================================

Use:

Semantic HTML

Accessible forms

Keyboard navigation

Focus states

Clear labels

Good contrast

Meaningful buttons

Accessible dialogs


Admin interfaces contain important actions, so accidental
clicks should be minimized.
